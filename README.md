## 🚀 소개

**Anti Academy**는 단순한 코드 저장소가 아닙니다. 이것은 **마스터리 멘토링 프로그램**입니다.
목표는 단순히 "돌아가게 만드는" 것에서 **프로덕션 수준의 확장 가능하고 유지보수 가능한** 소프트웨어를 만드는 것으로 도약하는 것입니다.

### 💡 핵심 철학
1.  **코딩보다 엔지니어링**: How 뒤에 있는 *Why*를 이해합니다.
2.  **패키지 독립적**: 아키텍처는 프레임워크 변경에도 살아남습니다.
3.  **제품 중심적**: 기술은 사용자 가치를 위한 수단입니다.
4.  **개념 우선**: 코드 작성 전에 스펙을 먼저 작성합니다.

## 📚 커리큘럼 & 프로젝트

이 여정은 점진적인 레벨로 구성되어 있으며, 각 레벨은 새로운 복잡도와 엔지니어링 과제를 도입합니다.

### 🟢 Level 1: 기초 [`habit_flow`]
> **상태:** ✅ 완료 (Phase 1-8)
>
> **핵심 주제:** 아키텍처 & 구조화된 상태 관리

기본 아키텍처 확립에 집중한 습관 추적 앱.
*   **핵심 기술**: Clean Architecture, Riverpod (Notifier), GoRouter.
*   **엔지니어링**: 오프라인 우선 (SharedPreferences/Hive), Optimistic UI 업데이트.
*   **결과**: UI 구현 세부사항에서 분리된 견고하고 테스트 가능한 코드베이스.

### 🟡 Level 2: 고급 엔지니어링 [`bridge`]
> **상태:** 🚧 진행 중 (Phase 7 완료)
>
> **핵심 주제:** TDD, 복잡한 백엔드 통합 & 실시간

지역 기반 시간 화폐 & 재능 공유 소셜 플랫폼.
*   **핵심 기술**: Supabase (Auth, DB, Realtime, Storage), Edge Functions.
*   **엔지니어링**: TDD(테스트 주도 개발), 고급 상태 머신, 보안 (RLS).
*   **과제**: 복잡한 실시간 상태와 관계형 데이터 관리.

### 🔴 Level 3: 심층 탐구 (계획 중)
> **핵심 주제:** 성능 & 내부 구조
>
> **주제**: RenderObject, Custom Painter, Platform Channel, FFI.

## 🛠 기술 스택

확장성을 위해 설계된 현대적이고 견고한 스택을 사용합니다.

| 도메인 | 기술 | 철학 |
| :--- | :--- | :--- |
| **언어** | **Dart** | 100% Null Safety, 강타입. |
| **프레임워크** | **Flutter** | 크로스 플랫폼, 선언형 UI. |
| **상태** | **Riverpod** | 컴파일 안전, 불변 상태 관리. |
| **내비게이션** | **GoRouter** | 딥링크 지원, 선언형 라우팅. |
| **백엔드** | **Supabase** | 오픈소스 Firebase 대안 (Postgres). |
| **테스팅** | **Flutter Test** | 유닛, 위젯, 통합 테스트. |
