## 🚀 About checks
**Anti Academy** is not just a repository; it's a **Mastery Mentoring Program**.
The goal is to transition from simply "making it work" to building **production-grade, scalable, and maintainable software**.

### 💡 Core Philosophy
1.  **Engineering Over Coding**: Understanding the *Why* behind the *How*.
2.  **Package Agnostic**: Architecture survives framework changes.
3.  **Product-Centric**: Tech serves the user value, not the other way around.
4.  **Concept First**: Write the spec before writing the code.

## 📚 Curriculum & Projects

The journey consists of progressive levels, each introducing new complexity and engineering challenges.

### 🟢 Level 1: Foundation [`habit_flow`]
> **Status:** ✅ Complete (Phase 1-3)
>
> **Focus:** Architecture & Structured State Management

A habit tracking app focused on establishing the base architecture.
*   **Key Tech**: Clean Architecture, Riverpod (Notifier), GoRouter.
*   **Engineering**: Offline-first (Hive), Optimistic UI updates.
*   **Result**: A robust, testable codebase decoupled from UI implementation details.

### 🟡 Level 2: Advanced Engineering [`bridge`]
> **Status:** 🚧 In Progress (Phase 1 Complete)
>
> **Focus:** TDD, Complex Backend Integration & Realtime

A local time-banking & skill-sharing social platform.
*   **Key Tech**: Supabase (Auth, DB, Realtime, Storage), Edge Functions.
*   **Engineering**: Test-Driven Development (TDD), Advanced State Machines, Security (RLS).
*   **Challenge**: Managing complex realtime state and relational data.

### 🔴 Level 3: Deep Dive (Planned)
> **Focus:** Performance & Internals
>
> **Topics**: RenderObject, Custom Painters, Platform Channels, FFI.

## 🛠 Technology Stack

We use a modern, opinionated stack designed for scalability.

| Domain | Technology | Philosophy |
| :--- | :--- | :--- |
| **Language** | **Dart** | 100% Null Safety, Strong Typing. |
| **Framework** | **Flutter** | Cross-platform, Declarative UI. |
| **State** | **Riverpod** | Compile-safe, Immutable state management. |
| **Navigation** | **GoRouter** | Deep-linking support, declarative routing. |
| **Backend** | **Supabase** | The open source Firebase alternative (Postgres). |
| **Testing** | **Flutter Test** | Unit, Widget, and Integration tests. |
